# 日ノ出市 / HINODE CITY

ブラウザで遊べる2.5D街づくり＋都市経営シミュレーション。**既存実装とは別のゼロベース再構築版**。

## 動かす

```bash
npm run dev
# http://localhost:4173
npm run check
```

依存パッケージはゼロ。静的ファイルだけで起動します。Cloudflare Workers Static Assetsへデプロイする場合：

```bash
npx wrangler login
npx wrangler deploy
```

Cloudflare側の接続・認証・公開設定は別途必要です。

## 操作

- 左メニュー/下部バーで道路、住宅、商業、工業、公園、学校、病院を選択
- キャンバスをドラッグして道路・用途地域を塗る（右クリック／Space+ドラッグで地図を移動）
- ホイールでズーム、マップ右下ボタンでも調整
- マップをクリックすると区画の状態を検査
- 時間停止、速度変更、1か月進める
- 政策タブで住民税と公共サービス予算を変更
- 保存/復元：IndexedDB。自動保存と手動保存、JSONエクスポートに対応

## アーキテクチャ

- `public/js/map.js`：マップ生成・地形・道路アクセス
- `public/js/engine.js`：決定的な都市計算、建設コマンドと統計
- `public/js/render.js`：Canvas 2Dでの2.5D描画、パン／ズーム／クリック
- `public/js/persistence.js`：IndexedDBセーブとバックアップ
- `public/js/main.js`：UIイベント統合

ゲーム内の通貨は「C」、毎月決算。人口・雇用・税収・サービス予算・交通混雑・政策を軽量な集計モデルで連動させています。

## 仕様限界

初回の**遊べる縦切りプロトタイプ**です。個別住民AI、経路探索に基づく交通、複数段階の企業サプライチェーン、選挙、オンライン同期は未実装。クラウドセーブは未実装で、この端末／ブラウザのIndexedDBに保存します。設計時点の数値は仮値です。

## データについて

- `schemaVersion: 1` の保存形式を使います。
- 直近60か月の集計履歴のみ保存します（肥大化防止）。
- 別バージョンの保存データは無理に読み込まず、警告します。
- `npm run check` はロジックのテスト。見た目とスマホ実機テストは別途必要です。
